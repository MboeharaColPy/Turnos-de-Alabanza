# Turnos de Alabanza

Es una aplicación para definir los turnos de un grupo de alabanza y consultar el listado de canciones con sus respectivas notas.

---

## 📥 Descarga e Instalación

### 📱 Opción 1: Descarga directa (Android)
Puedes descargar directamente el archivo ejecutable para Android (.apk) e instalarlo en tu dispositivo:

- **[⬇️ Descargar APK (Última versión)](https://github.com/MboeharaColPy/Turnos-de-Alabanza/releases/tag/v2.9.0)**

**Instrucciones:**
1. Descarga el archivo `.apk` desde el enlace anterior
2. Abre el archivo en tu dispositivo Android
3. Permite la instalación desde fuentes desconocidas si es necesario
4. ¡Listo! La aplicación estará instalada

---

### 🌐 Opción 2: Acceso Web (iPhone, iPad y navegadores)
Si prefieres no instalar una APK o usas dispositivos Apple, puedes acceder desde tu navegador:

- **[🔗 Abre la aplicación web aquí](https://6a97404db2b3a5b12fbcd85c--cozy-elf-fe9291.netlify.app/)**

**Instalar como aplicación:**
1. Abre el enlace anterior en tu navegador
2. Selecciona la opción **"Agregar a la pantalla principal"** (iOS) o **"Instalar aplicación"** (Android/PC)
3. ¡Listo! Tendrás acceso a la aplicación como si fuera una app nativa

**Ventajas de la web:**
- ✅ Funciona en iPhone, iPad, Mac y navegadores
- ✅ Sin necesidad de descargar APK
- ✅ Actualiza automáticamente
- ✅ Funciona offline después de la primera carga
